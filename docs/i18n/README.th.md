OpenWithPanel เป็นแอป macOS ฟรีและโอเพนซอร์สสำหรับจัดการ **แอปเริ่มต้น**: เลือกว่าแอปไหนจะเปิดไฟล์แต่ละประเภท นามสกุลไฟล์แต่ละแบบ และลิงก์แต่ละชนิด ได้ในหน้าต่างเดียว และยังทำสิ่งที่ Finder ทำไม่ได้: ตั้งโปรแกรมแก้ไขของคุณเป็นแอปเริ่มต้นสำหรับ **ไฟล์ที่ไม่มีนามสกุล** เช่น `.env`, `.gitignore`, `Dockerfile` และ `.npmrc`

## ทำไมต้อง OpenWithPanel

macOS จัดไฟล์ที่ไม่มีนามสกุลส่วนใหญ่เป็น `public.data` และไม่ยอมให้แอปใดเป็นแอปเริ่มต้นของประเภทนี้ **ขอรายละเอียด › เปิดด้วย › เปลี่ยนทั้งหมด…** ใน Finder ไม่มีผลกับไฟล์เหล่านี้ และเครื่องมือบรรทัดคำสั่งจะล้มเหลวพร้อมข้อผิดพลาด `-50` ส่วน **เปิดเสมอด้วย** ใน Finder มีผลเฉพาะกับไฟล์เดียวที่คุณเลือกเท่านั้น

ผลก็คือ `.env`, `.gitignore`, `Dockerfile` และไฟล์ทำนองเดียวกันยังคงเปิดใน TextEdit — หรือเปิดไม่ได้เลย — ไม่ว่าคุณจะตั้งค่าอย่างไร OpenWithPanel แก้ปัญหานี้ด้วยแอปผู้ช่วยขนาดเล็กชื่อ OpenWithPanel Helper ซึ่งอธิบายไว้ใน [หลักการทำงาน](#หลักการทำงาน)

OpenWithPanel ยังเติมส่วนที่ macOS ขาดไปในด้านอื่นด้วย: เมื่อแอปที่เพิ่งติดตั้ง (โดยทั่วไปคือ Xcode) แย่งการเชื่อมโยงไฟล์ของคุณไป macOS จะไม่แจ้งให้ทราบ และไม่มีปุ่มสำหรับคืนทุกอย่างกลับเป็นแบบเดิม

## คุณสมบัติ

- **แอปเริ่มต้นตามกลุ่ม** ประเภทไฟล์ถูกจัดกลุ่มตามการใช้งาน — ข้อความ, Markdown, โค้ด, การกำหนดค่าและข้อมูล, ไฟล์ที่ไม่มีนามสกุล, PDF, เอกสาร, รูปภาพ, วิดีโอ, เสียง, ไฟล์บีบอัด — และแต่ละกลุ่มมีเมนูแอปหนึ่งเมนู
- **นำไปใช้ในครั้งเดียว** กำหนดรูปแบบทั้งกลุ่มได้พร้อมกันโดยไม่ต้องยืนยันทีละรายการ การเปลี่ยนแปลงจะมีผลภายในไม่กี่วินาที
- **ข้อยกเว้นรายรูปแบบ** ขยายกลุ่มเพื่อกำหนดแอปเฉพาะให้รูปแบบเดียว เช่น `.md` หรือ `.py` หากเปลี่ยนแอปของกลุ่มในภายหลัง ข้อยกเว้นเหล่านี้จะไม่ถูกแตะต้อง
- **ไฟล์ที่ไม่มีนามสกุล** เปิด `.env`, `Dockerfile`, `.gitignore` และไฟล์ไม่มีนามสกุลอื่นๆ ในโปรแกรมแก้ไขที่คุณเลือก แม้โปรแกรมนั้นจะไม่ได้ประกาศว่ารองรับไฟล์เหล่านี้
- **นามสกุลกำหนดเอง** เพิ่มนามสกุลใดก็ได้ที่ไม่อยู่ในรายการ รวมถึงนามสกุลที่ macOS รู้จักเพียงในฐานะประเภทชั่วคราว เช่น `.go`, `.rs`, `.kt`, `.dart` และ `.lua`
- **แอปเริ่มต้นสำหรับลิงก์** เลือกแอปสำหรับลิงก์เว็บ (`http`, `https`), อีเมล (`mailto`), การสมัครรับปฏิทิน (`webcal`), การโทร, ข้อความ SMS, FaceTime, SSH, FTP และการแชร์หน้าจอ — หรือเลือก **ไม่เปิด** เพื่อให้การคลิกลิงก์ประเภทนั้นไม่เกิดผลใดๆ
- **ค้นหาด้วยนามสกุล** พิมพ์ `py` หรือ `env` เพื่อข้ามไปยังแถวที่ถูกต้องทันที
- **วินิจฉัยไฟล์ใดก็ได้** ลากไฟล์มาวางเพื่อดูว่าทำไมไฟล์นั้นจึงเปิดในแอปหนึ่งๆ แล้วเลือกแอปอื่นได้ทันทีตรงนั้น ลากโฟลเดอร์มาวางเพื่อค้นหาไฟล์ที่มีการตั้งค่า **เปิดด้วย** ของตัวเองและล้างออก
- **แจ้งเตือนเมื่อถูกแย่งการเชื่อมโยง** หากแอปอื่น (Xcode, เบราว์เซอร์) เข้ามาแทนที่การเชื่อมโยงที่คุณตั้งไว้ OpenWithPanel จะแสดงแบนเนอร์พร้อมปุ่มแก้ไขในคลิกเดียว
- **เลิกทำและกู้คืน** สแนปช็อตจะถูกบันทึกก่อนการเปลี่ยนแปลงทุกครั้ง เลิกทำด้วย `⌘Z` กู้คืนสแนปช็อตก่อนหน้าใดก็ได้ หรือกู้คืนทุกอย่างกลับสู่สภาพก่อนที่ OpenWithPanel จะเปลี่ยนแปลงสิ่งใด โดยแสดงตัวอย่างการเปลี่ยนแปลงแต่ละรายการก่อน
- **กฎโฟลเดอร์** ทางเลือกสำรองที่ไม่บังคับ ซึ่งกำหนดให้ไฟล์ไม่มีนามสกุลในโฟลเดอร์ที่เลือก เช่น `~/Projects` เปิดในโปรแกรมแก้ไขของคุณ โดยใช้เฉพาะ API ทางการของ macOS
- **โหมดนักพัฒนา** กฎที่ส่งต่อไฟล์ตามรูปแบบชื่อ (เช่น `Dockerfile*`) โฟลเดอร์ หรือเนื้อหาว่าเป็นข้อความหรือไบนารี; สายการตัดสินใจฉบับเต็มในหน้าวินิจฉัย รวมถึงประเภทที่แต่ละแอปประกาศไว้และลำดับความสำคัญ (rank); นำเข้าและส่งออกค่าที่ตั้งไว้ล่วงหน้า
- **ถอนการติดตั้งอย่างหมดจด** ตัวถอนการติดตั้งในตัวจะคืนการเชื่อมโยงทุกรายการกลับไปยังแอปเดิมก่อนย้าย OpenWithPanel ไปยังถังขยะ
- **15 ภาษา** อังกฤษ จีนตัวย่อ จีนตัวเต็ม ญี่ปุ่น เกาหลี เยอรมัน ฝรั่งเศส สเปน โปรตุเกส อินโดนีเซีย ไทย เวียดนาม อาหรับ รัสเซีย และฮินดี สลับได้ภายในแอป

## การติดตั้ง

ต้องใช้ macOS 26 Tahoe ขึ้นไป

1. เปิด [หน้า Releases](https://github.com/zhaojiannet/openwithpanel/releases) แล้วดาวน์โหลด `OpenWithPanel-<version>.dmg` จากส่วน **Assets** ของรุ่นล่าสุด
2. คลิกสองครั้งที่ไฟล์ DMG ที่ดาวน์โหลดมาเพื่อเปิด
3. ลาก **OpenWithPanel** ไปวางบนโฟลเดอร์ **แอปพลิเคชัน** ที่แสดงอยู่ในหน้าต่างเดียวกัน
4. นำ DMG ออก แล้วเปิด OpenWithPanel จากโฟลเดอร์แอปพลิเคชัน ในครั้งแรก macOS จะขอให้คุณอนุญาต ดู [การเปิดครั้งแรก](#การเปิดครั้งแรก)

ไม่มีตัวติดตั้งและไม่ต้องใช้รหัสผ่านผู้ดูแลระบบ

**การอัปเดต:** ดาวน์โหลดไฟล์ DMG ใหม่แล้วลาก OpenWithPanel ไปไว้ในแอปพลิเคชันอีกครั้งเพื่อแทนที่ตัวเดิม การตั้งค่า กฎ และสแนปช็อตของคุณจะยังอยู่ครบ หากต้องการดูว่ามีเวอร์ชันใหม่หรือไม่ ให้เลือก **OpenWithPanel › ตรวจหาอัปเดต…**

**การถอนการติดตั้ง:** ดู [การถอนการติดตั้ง](#การถอนการติดตั้ง)

### การเปิดครั้งแรก

OpenWithPanel ยังไม่ได้รับการรับรอง (notarize) จาก Apple macOS จึงบล็อกไว้เมื่อคุณเปิดครั้งแรก ให้อนุญาตหนึ่งครั้ง:

1. คลิกสองครั้งที่ OpenWithPanel เมื่อ macOS แจ้งว่าไม่สามารถตรวจสอบ OpenWithPanel ได้ ให้คลิก **เสร็จสิ้น** อย่าคลิกปุ่มสีน้ำเงิน **ย้ายไปยังถังขยะ**

   <img src="../assets/first-launch-1.png" width="372" alt="คำเตือนแรก: คลิกเสร็จสิ้น">

2. เปิด **การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย** เลื่อนลงไปที่ **ความปลอดภัย** แล้วคลิก **ยืนยันจะเปิด** ข้าง OpenWithPanel ปุ่มนี้จะแสดงอยู่ประมาณหนึ่งชั่วโมงหลังขั้นตอนที่ 1

   <img src="../assets/first-launch-2.png" width="560" alt="ความเป็นส่วนตัวและความปลอดภัย: คลิกยืนยันจะเปิด">

3. ป้อนรหัสผ่านเข้าสู่ระบบหรือใช้ Touch ID แล้วคลิก **ยืนยันจะเปิด** อีกครั้งในหน้าต่างโต้ตอบที่ตามมา

   <img src="../assets/first-launch-3.png" width="372" alt="การยืนยัน: คลิกยืนยันจะเปิด">

หลังจากนี้ OpenWithPanel จะเปิดได้ตามปกติ แอปผู้ช่วยในตัวจะได้รับอนุญาตไปพร้อมกัน ไฟล์ที่ไม่มีนามสกุลจึงเปิดได้โดยไม่มีข้อความถามอีก ใน DMG ยังมีขั้นตอนเหล่านี้อยู่ในไฟล์ `First Launch.txt` ภาพหน้าจอแสดงอินเทอร์เฟซภาษาอังกฤษ ส่วนชื่อปุ่มใน macOS ภาษาไทยคือชื่อที่เขียนไว้ข้างต้น

## วิธีใช้

### กลุ่มประเภทไฟล์

แท็บ **ประเภทไฟล์** แสดงทุกกลุ่มเป็นการ์ด:

| กลุ่ม | ประกอบด้วย |
|---|---|
| ข้อความ | `.txt` `.log` |
| Markdown | `.md` `.markdown` |
| โค้ด | ภาษาโปรแกรมยอดนิยม ดูด้านล่าง |
| การกำหนดค่าและข้อมูล | `.json` `.yaml` `.toml` `.xml` `.ini` `.plist` `.csv` |
| ไฟล์ที่ไม่มีนามสกุล | `.env` `Dockerfile` `.gitignore` และไฟล์ทำนองเดียวกัน |
| PDF | `.pdf` |
| เอกสาร | `.rtf` `.docx` `.doc` `.pages` `.odt` |
| รูปภาพ, วิดีโอ, เสียง, ไฟล์บีบอัด | รูปแบบที่ใช้กันทั่วไปของแต่ละกลุ่ม |
| กำหนดเอง | นามสกุลที่คุณเพิ่มเองซึ่งไม่เข้ากลุ่มอื่น แสดงเฉพาะเมื่อมีรายการอยู่ |

กลุ่มโค้ดครอบคลุมภาษาที่ผู้ตอบแบบสำรวจ Stack Overflow 2025 Developer Survey ใช้อย่างน้อย 5%: JavaScript, TypeScript (`.tsx`), Python, Java, C, C++, C#, PHP, Ruby, Swift, Go, Rust, Kotlin, Dart, Lua, Shell (sh, bash, zsh), PowerShell, SQL และแอสเซมบลี รวมถึง CSS, Makefile และ JSX ภาษาอื่นๆ คุณเพิ่มเองได้ ดู [เพิ่มนามสกุลไฟล์](#เพิ่มนามสกุลไฟล์)

### กำหนดแอปให้ทั้งกลุ่ม

เลือกแอปจากเมนูทางขวาของการ์ด จากนั้นทุกรูปแบบในกลุ่มจะเปิดด้วยแอปนั้น เมนูจะแสดงแอปที่ macOS เห็นว่าเปิดกลุ่มนั้นได้ เลือก **อื่นๆ…** เพื่อเลือกแอปใดก็ได้จากโฟลเดอร์แอปพลิเคชัน

### กำหนดแอปเฉพาะให้รูปแบบเดียว

คลิกแถวของกลุ่ม หรือลูกศรทางซ้ายของแถว เพื่อขยายกลุ่ม แต่ละรูปแบบมีแถวของตัวเอง พร้อมไอคอนระบบของไฟล์นั้นและมีนามสกุลเป็นชื่อแถว เลือกแอปอื่นในเมนูของแถวใด รูปแบบนั้นจะใช้แอปนั้นนับจากนี้ แถวจะมีเครื่องหมาย **ตั้งค่าแยก** และแถวของกลุ่มจะแสดงจำนวนรูปแบบที่ตั้งค่าแยก

- รูปแบบที่ไม่มีแอปของตัวเองจะแสดง **เหมือนกลุ่ม** เป็นสีเทาในเมนู
- หากต้องการให้รูปแบบกลับไปใช้ตามกลุ่ม ให้เลือก **ใช้ตามกลุ่ม** ในเมนูของรูปแบบนั้น
- การเปลี่ยนแอปของกลุ่มในภายหลังจะไม่แตะต้องรูปแบบที่มีแอปของตัวเอง

กลุ่มที่มีมากกว่า 8 รูปแบบจะแสดงเฉพาะรูปแบบที่คุณตั้งค่าแยกหรือเพิ่มเอง ส่วน **แสดงทั้งหมด N รูปแบบ** ที่ด้านล่างจะแสดงรายการที่เหลือ เมื่อกลุ่มโค้ดแสดงทั้งหมด จะแบ่งเป็นส่วนต่างๆ เช่น เว็บ, ระบบและแอป, JVM และ สคริปต์และเชลล์

### ค้นหา

พิมพ์นามสกุล เช่น `py` หรือ `env` ลงในช่องค้นหาที่มุมขวาบน กลุ่มที่ตรงกันจะขยายออกพร้อมรูปแบบทั้งหมด และแถวที่ตรงกันจะถูกไฮไลต์ หากนามสกุลนั้นไม่อยู่ในกลุ่มใดเลย ผลการค้นหาจะมี **เพิ่ม…** ให้

### เพิ่มนามสกุลไฟล์

ใช้ **เพิ่มนามสกุลไฟล์…** ที่ด้านล่างของรายการ หรือ **เพิ่ม…** ในผลการค้นหา

1. พิมพ์นามสกุล เช่น `nim` แผ่นงานจะแสดงว่า macOS รู้จักนามสกุลนี้เป็นอะไร
2. OpenWithPanel จะแนะนำกลุ่มตามข้อมูลนั้น: ซอร์สโค้ดไปที่โค้ด รูปภาพไปที่รูปภาพ สิ่งที่ไม่รู้จักไปที่กำหนดเอง คุณเลือกกลุ่มอื่นได้
3. คลิก **เพิ่ม** รูปแบบจะปรากฏในกลุ่มนั้นพร้อมเครื่องหมาย **กำหนดเอง** และใช้แอปตามกลุ่ม คุณยังกำหนดแอปเฉพาะให้ได้ด้วย

นามสกุลที่อยู่ในกลุ่มแล้วจะไม่ถูกเพิ่มซ้ำ แผ่นงานจะบอกว่าอยู่ในกลุ่มใด รูปแบบที่คุณเพิ่มเองจะมีปุ่มลบอยู่ในแถว

### นำไปใช้

การเปลี่ยนแปลงทั้งหมดข้างต้นจะถูกพักไว้ก่อน แถบที่ด้านล่างของหน้าต่างจะแสดงจำนวนการเปลี่ยนแปลงที่รออยู่ **นำไปใช้** จะทำให้มีผล และ **ละทิ้ง** จะยกเลิก

- การเปลี่ยนแปลงประเภทไฟล์ไม่ต้องยืนยัน ไม่ว่าคุณจะเปลี่ยนกี่รูปแบบ OpenWithPanel จะเขียนลงในค่าการตั้งค่าของระบบในครั้งเดียว แล้วให้ระบบโหลดใหม่เพียงครั้งเดียว ทุกอย่างจะมีผลภายในไม่กี่วินาที
- การเปลี่ยนแปลงลิงก์และไฟล์เว็บ (`.html`) ยังคงขอให้คุณยืนยันในหน้าต่างโต้ตอบของระบบ เช่น เมื่อคุณเปลี่ยนเว็บเบราว์เซอร์ การเปลี่ยนเบราว์เซอร์อย่างเงียบๆ คือสิ่งที่มัลแวร์ยึดเบราว์เซอร์ทำ macOS จึงควรถามคุณโดยตรง
- หากเขียนไม่สำเร็จ (เช่น เพราะสิทธิ์การเข้าถึง) หรือรูปแบบใดไม่มีผล OpenWithPanel จะตั้งค่ารูปแบบนั้นอีกครั้งผ่าน API ของระบบทีละรายการ แล้ว macOS จะถามว่าจะใช้แอปใหม่หรือคงแอปเดิมไว้ หากคุณคงแอปเดิม OpenWithPanel จะบันทึกรูปแบบนั้นว่าตั้งค่าแยกไว้กับแอปนั้น และจะไม่แตะต้องอีก
- หลังนำไปใช้ OpenWithPanel จะอ่านสถานะจริงของระบบกลับมา รายการจึงแสดงสิ่งที่มีผลจริงเสมอ

### เลิกทำและกู้คืน

- **แก้ไข › เลิกทำ** (`⌘Z`) จะเลิกทำการนำไปใช้ครั้งล่าสุด คุณเลิกทำต่อกันได้หลายครั้ง
- ปุ่มลูกศรวงกลมในแถบเครื่องมือคือ **กู้คืนเป็นค่าเริ่มต้น**: ทุกประเภทไฟล์และลิงก์ที่ OpenWithPanel เปลี่ยนจะชี้กลับไปยังแอปที่ใช้อยู่เมื่อคุณเปิด OpenWithPanel ครั้งแรก การเปลี่ยนแปลงแต่ละรายการจะแสดงให้ดูก่อนลงมือ

macOS ไม่มีวิธีลบการเชื่อมโยงไฟล์ ทำได้เพียงชี้ไปยังแอปอื่น การกู้คืนจึงหมายถึงการชี้แต่ละประเภทกลับไปยังแอปที่บันทึกไว้ในสแนปช็อต ประเภทที่เดิม macOS เลือกแอปเองจะได้รับการตั้งค่าที่ระบุแอปเดียวกันนั้นอย่างชัดเจน และจะเปิดเหมือนเดิมทุกประการ

### ลิงก์

ใต้ประเภทไฟล์ มีการ์ดสำหรับกำหนดแอปของลิงก์แต่ละชนิด:

| แถว | รูปแบบ URL |
|---|---|
| เว็บเบราว์เซอร์ | `http:` `https:` |
| อีเมล | `mailto:` |
| การสมัครรับปฏิทิน | `webcal:` |
| การโทร, ข้อความ SMS, FaceTime | `tel:` `sms:` `facetime:` |
| SSH, FTP, การแชร์หน้าจอ | `ssh:` `ftp:` `vnc:` |

ลิงก์ทุกชนิดที่มีแอปบน Mac ของคุณรองรับจะแสดงอยู่ในรายการ ที่ด้านล่างของแต่ละเมนูมี **ไม่เปิด**: เมื่อเลือก การคลิกลิงก์ชนิดนั้นในแอปใดก็ตามจะไม่เกิดผลใดๆ — เช่น เพื่อไม่ให้หมายเลขโทรศัพท์บนหน้าเว็บเริ่มการโทร หากต้องการยกเลิก ให้เลือกแอปในเมนูอีกครั้ง การเลือก **ไม่เปิด** ให้เว็บเบราว์เซอร์จะขอให้ยืนยันก่อน เพราะจะไม่มีลิงก์เว็บใดเปิดได้เลย คุณยังค้นหารูปแบบ URL (เช่น `mailto`) หรือชื่อแถวได้ด้วย

ลิงก์ถูกพักไว้ นำไปใช้ บันทึกสแนปช็อต เลิกทำ และกู้คืนได้เหมือนประเภทไฟล์ทุกประการ การเปลี่ยนเว็บเบราว์เซอร์จะขอให้ยืนยันในหน้าต่างโต้ตอบของระบบ บน macOS 27 การเปลี่ยน `http` จะเปลี่ยน `https` ไปด้วย และ OpenWithPanel จะไม่ตั้งค่า `https` ซ้ำ คุณจึงยืนยันเพียงครั้งเดียว

## การวินิจฉัย

สลับไปที่แท็บ **วินิจฉัย** ที่ด้านบนของหน้าต่าง

**ทำไมไฟล์จึงเปิดในแอปนี้** ลากไฟล์มาวางในกรอบเส้นประ ผลลัพธ์จะแสดงว่าแอปใดเปิดไฟล์นั้นและเพราะอะไร:

- ไฟล์มีการตั้งค่า **เปิดด้วย** ของตัวเอง ซึ่งตั้งไว้ใน **ขอรายละเอียด** ของ Finder
- OpenWithPanel Helper ได้รับไฟล์นั้น และกฎหรือการตั้งค่าของกลุ่มส่งไฟล์ต่อไปยังแอป
- คุณเลือกแอปนี้ให้กับไฟล์ชนิดนี้
- ไม่ได้ตั้งค่าอะไรไว้ macOS จึงเลือกแอปเอง

ใต้ผลลัพธ์ **ใช้แอปอื่นแทน** จะสลับไปใช้แอปอื่นได้ทันที หากไฟล์มีการตั้งค่า **เปิดด้วย** ของตัวเอง จะแสดง **ลบการตั้งค่าของไฟล์นี้** แทน

**ค้นหาไฟล์ที่มีการตั้งค่า "เปิดด้วย" ของตัวเอง** ลากโฟลเดอร์มาวางในกรอบเส้นประ OpenWithPanel จะแสดงทุกไฟล์ในโฟลเดอร์ที่มีการตั้งค่า **เปิดด้วย** ของตัวเอง พร้อมแอปที่ไฟล์นั้นชี้ไป เลือกไฟล์แล้วคลิก **ลบการตั้งค่าของไฟล์เหล่านั้น** จากนั้นไฟล์จะใช้การตั้งค่าตามชนิดของตน การสแกนจะข้ามโฟลเดอร์ `.git`, `node_modules`, `.build`, `DerivedData`, `Pods`, `vendor`, `.venv` และ `__pycache__`

**ส่งออกรายงานการวินิจฉัย** ปุ่ม **ส่งออกรายงานการวินิจฉัย…** ที่ด้านล่างของแท็บจะบันทึกรายงานข้อความที่มีการกำหนดค่าของคุณ แอปที่เปิดแต่ละประเภทที่ OpenWithPanel จัดการอยู่ในขณะนี้ บันทึกของเซสชันนี้ และไฟล์ที่คุณเพิ่งวินิจฉัย ส่งรายงานนี้ให้ผู้พัฒนาเมื่อแจ้งปัญหา

## การตั้งค่า

เปิด **OpenWithPanel › การตั้งค่า…** หรือกด `⌘,`

**ทั่วไป**

- **ภาษา:** เลือก **ตามระบบ** หรือภาษาใดภาษาหนึ่งใน 15 ภาษา แล้วคลิก **เปิดใหม่ตอนนี้** หากมีการเปลี่ยนแปลงที่ยังไม่ได้นำไปใช้ ให้นำไปใช้หรือละทิ้งก่อน
- **โหมดนักพัฒนา:** แสดงรายละเอียดเพิ่มเติม ดู [โหมดนักพัฒนา](#โหมดนักพัฒนา) โหมดนี้เปลี่ยนเฉพาะสิ่งที่แสดง ไม่เปลี่ยนการตั้งค่าของคุณ

**กฎโฟลเดอร์**

ทางเลือกสำรองสำหรับกรณีที่วิธีที่ใช้กับไฟล์ที่ไม่มีนามสกุลใช้งานไม่ได้ เพิ่มโฟลเดอร์แล้วเลือกแอป OpenWithPanel จะให้ไฟล์ข้อความที่ไม่มีนามสกุลทุกไฟล์ในโฟลเดอร์นั้นมีการตั้งค่า **เปิดด้วย** ของตัวเองที่ชี้ไปยังแอปนั้น

- ไฟล์ไบนารีและไฟล์ที่คุณตั้งค่าเองจะไม่ถูกแตะต้อง
- ไฟล์ใหม่จะได้รับการจัดการทุกครั้งที่คุณเปิด OpenWithPanel หรือทันทีด้วย **นำไปใช้ตอนนี้**
- **ยกเลิกการตั้งค่าโฟลเดอร์ทั้งหมด** จะคืนทุกไฟล์ที่ OpenWithPanel เปลี่ยนกลับเป็นแบบเดิม
- **ข้ามโฟลเดอร์ที่ชื่อ** แก้ไขได้ โดยค่าเริ่มต้นจะมีรายชื่อโฟลเดอร์เดียวกับที่การสแกนโฟลเดอร์ในหน้าวินิจฉัยข้าม

**ประวัติ**

แสดงสแนปช็อตที่บันทึกไว้ก่อนการนำไปใช้แต่ละครั้ง สูงสุด 20 รายการ เรียงจากใหม่ไปเก่า รายการสุดท้าย **เริ่มต้น (ก่อนที่ OpenWithPanel จะเปลี่ยนแปลงอะไร)** คือสถานะที่บันทึกไว้เมื่อคุณเปิด OpenWithPanel ครั้งแรก กู้คืนรายการใดก็ได้ด้วย **กู้คืน…** โดยแสดงตัวอย่างความแตกต่างก่อน

**สิ่งที่ OpenWithPanel เขียน**

แสดงทุกตำแหน่งที่ OpenWithPanel เปลี่ยนแปลงหรือเขียนข้อมูลบน Mac ของคุณ แต่ละรายการมีปุ่ม **แสดงใน Finder**:

- **การเชื่อมโยงไฟล์:** จำนวนรายการ (ประเภทไฟล์และลิงก์) ที่ OpenWithPanel จัดการ
- **รายการการตั้งค่า LaunchServices:** รายการที่ OpenWithPanel เขียนไว้สำหรับประเภทไฟล์ รวมถึงไฟล์ที่ไม่มีนามสกุล
- **OpenWithPanel Helper:** อยู่ภายในแอป OpenWithPanel
- **กฎและสแนปช็อต:** `~/Library/Application Support/net.zhaojian.openwithpanel/`
- **การตั้งค่า “เปิดด้วย” รายไฟล์:** มีเฉพาะเมื่อคุณใช้กฎโฟลเดอร์

OpenWithPanel ไม่ทำงานเบื้องหลัง ไม่มีรายการเข้าสู่ระบบ และไม่เก็บข้อมูล แอปจะเชื่อมต่ออินเทอร์เน็ตเฉพาะเมื่อคุณเลือก **ตรวจหาอัปเดต…** เพื่ออ่านหมายเลขเวอร์ชันล่าสุดจาก GitHub

### การถอนการติดตั้ง

ที่ด้านล่างของ **สิ่งที่ OpenWithPanel เขียน** ให้คลิก **ถอนการติดตั้ง OpenWithPanel…** แล้วเลือกว่าจะลบกฎและสแนปช็อตด้วยหรือไม่ จากนั้น OpenWithPanel จะ:

1. ชี้ทุกประเภทไฟล์และลิงก์ที่เปลี่ยนไว้กลับไปยังแอปเดิม
2. ยกเลิกการตั้งค่ารายไฟล์ทั้งหมดที่กฎโฟลเดอร์สร้างไว้
3. ลบหรือเก็บ `~/Library/Application Support/net.zhaojian.openwithpanel/` ตามที่คุณเลือก
4. ย้ายตัวเองไปยังถังขยะ

หากมีประเภทไฟล์หรือลิงก์ใดที่ชี้กลับไม่ได้ เช่น เพราะคุณปฏิเสธการยืนยันของระบบ การถอนการติดตั้งจะหยุดลงและจะไม่มีสิ่งใดถูกลบ

หากคุณเก็บกฎและสแนปช็อตไว้ เมื่อติดตั้ง OpenWithPanel ใหม่จะมีแบนเนอร์ที่คืนค่าการตั้งค่าทั้งหมดของคุณได้ในคลิกเดียว เครื่องมือล้างแอปที่ลบไฟล์ที่หลงเหลือของแอปเมื่อย้ายแอปไปยังถังขยะอาจลบกฎและสแนปช็อตที่คุณเลือกเก็บไว้ด้วย ให้ตั้งค่าเครื่องมือนั้นให้ข้าม OpenWithPanel

หากคุณลาก OpenWithPanel ไปที่ถังขยะเองแทน OpenWithPanel Helper จะถูกลบไปด้วย และ macOS จะยกเลิกการเชื่อมโยงที่ชี้ไปยังแอปผู้ช่วย ส่วนประเภทอื่นจะยังใช้แอปที่ OpenWithPanel ตั้งไว้ ไฟล์ `UNINSTALL.txt` ในโฟลเดอร์ Application Support อธิบายวิธีกู้คืนในกรณีนี้

## โหมดนักพัฒนา

เปิดใช้ได้ใน **การตั้งค่า › ทั่วไป** โหมดนี้จะเพิ่ม:

- ตัวระบุประเภทของระบบ (UTI) ใต้แต่ละรูปแบบ และป้าย **ตัวช่วย** บนรูปแบบที่ส่งผ่าน OpenWithPanel Helper
- สายการตัดสินใจฉบับเต็มในหน้าวินิจฉัย: ประเภท ประเภทแม่ ข้อความหรือไบนารี ผลการตัดสินใจ และวิธีที่แต่ละแอปที่เปิดไฟล์ได้ประกาศไว้ใน Info.plist (นามสกุลหรือประเภทที่ตรงกัน บทบาท และ rank)
- แท็บ **กฎ** ในหน้าต่างหลัก
- การจัดการ **ไฟล์ที่ไม่ใช่ข้อความ** และ **ค่าที่ตั้งไว้ล่วงหน้า** ในการตั้งค่า

**กฎ** กำหนดว่า OpenWithPanel Helper จะส่งไฟล์ที่ได้รับไปที่ใด กฎหนึ่งข้อประกอบด้วย:

- เงื่อนไข ซึ่งต้องกรอกอย่างน้อยหนึ่งข้อ: รูปแบบชื่อไฟล์ (เช่น `Dockerfile*` ไม่สนตัวพิมพ์เล็กใหญ่) โฟลเดอร์ที่บรรจุไฟล์ (เช่น `~/Projects`) และเนื้อหาเป็นข้อความหรือไบนารี
- ประเภทที่กฎใช้กับ ค่าเริ่มต้นคือ `public.data` (ไฟล์ที่ไม่มีนามสกุล) ประเภทอื่นที่คุณเพิ่มจะถูกส่งผ่าน OpenWithPanel Helper ด้วย
- ปลายทางของไฟล์: แอป, **แสดงใน Finder** หรือ **แอปเดิม**

กฎจะถูกตรวจจากบนลงล่าง และกฎแรกที่ตรงจะมีผล ลากเพื่อจัดลำดับใหม่ สวิตช์ทางซ้ายใช้ปิดกฎชั่วคราว กลุ่มที่ได้รับผลจากกฎจะแสดง **ควบคุมโดยกฎ** ในโหมดมาตรฐาน

**ไฟล์ที่ไม่ใช่ข้อความ** กำหนดว่า OpenWithPanel Helper จะทำอะไรกับไฟล์ไบนารี: **แสดงใน Finder** (ค่าเริ่มต้น), **เปิดด้วยแอปเดียวกัน** หรือ **เปิดด้วยแอปเดิม**

**ค่าที่ตั้งไว้ล่วงหน้า** ส่งออกการตั้งค่ากลุ่ม การตั้งค่ารายรูปแบบ นามสกุลกำหนดเอง และกฎของคุณเป็นไฟล์ JSON ที่นำเข้าบน Mac เครื่องอื่นได้ การตั้งค่าที่นำเข้าจะมีผลหลังจากคุณคลิก **นำไปใช้** กฎโฟลเดอร์และบันทึกแอปเดิมเป็นข้อมูลเฉพาะของ Mac แต่ละเครื่อง จึงไม่ถูกส่งออกและไม่ถูกเขียนทับเมื่อนำเข้า

## หลักการทำงาน

OpenWithPanel มาพร้อมแอปผู้ช่วยขนาดจิ๋วชื่อ **OpenWithPanel Helper** อยู่ภายในแพ็กเกจแอป เมื่อคุณเลือกโปรแกรมแก้ไขสำหรับไฟล์ที่ไม่มีนามสกุล OpenWithPanel จะชี้ `public.data` ไปที่แอปผู้ช่วย เมื่อคุณเปิดไฟล์ประเภทนี้ แอปผู้ช่วยจะตรวจสอบกฎของคุณและเนื้อหาของไฟล์ ส่งไฟล์ข้อความให้แอปที่คุณเลือก แสดงไฟล์ไบนารีใน Finder แล้วปิดตัวเอง แอปผู้ช่วยไม่ทำงานค้างไว้: macOS จะเริ่มแอปนี้เฉพาะเมื่อมีไฟล์หรือลิงก์ต้องส่งต่อ และแอปจะปิดตัวเองหลังว่างงานไม่ถึงหนึ่งวินาที แอปผู้ช่วยไม่มีหน้าต่างและไม่ปรากฏใน Dock ลิงก์ที่ตั้งเป็น **ไม่เปิด** จะถูกส่งไปยังแอปผู้ช่วยเช่นกัน และแอปผู้ช่วยจะเพิกเฉยต่อลิงก์นั้น

ไฟล์จะถือว่าเป็นไบนารีหาก 8 KB แรกมีไบต์ค่าศูนย์ (null) หรือไม่ใช่ UTF-8 ที่ถูกต้อง

ประเภทไฟล์ที่แอปที่คุณเลือกรองรับอยู่แล้ว เช่น `.md` หรือ `.py` จะถูกกำหนดให้แอปนั้นโดยตรงโดยไม่ผ่านแอปผู้ช่วย

macOS ไม่มี API สาธารณะสำหรับกำหนดแอปเริ่มต้นของ `public.data` และตั้งแต่ macOS 26.4 API สาธารณะจะขอให้ยืนยันการเปลี่ยนแปลงประเภทไฟล์ทีละประเภท ดังนั้น OpenWithPanel จึงเขียนการเปลี่ยนแปลงประเภทไฟล์ทั้งหมดลงในค่าการตั้งค่าของ LaunchServices ในครั้งเดียว แล้วรีสตาร์ทบริการ `lsd` หนึ่งครั้งเพื่อให้มีผล กลไกนี้ไม่มีเอกสารจาก Apple และอาจใช้งานไม่ได้หลังอัปเดตระบบ หากการเปลี่ยนแปลงใดไม่มีผล OpenWithPanel จะกลับไปใช้ API สาธารณะ ซึ่งจะขอให้คุณยืนยัน ส่วนไฟล์ที่ไม่มีนามสกุล OpenWithPanel จะเสนอกฎโฟลเดอร์แทน

## คำถามที่พบบ่อย

**จะเปลี่ยนแอปเริ่มต้นสำหรับไฟล์ที่ไม่มีนามสกุลบน Mac ได้อย่างไร**
เปิด OpenWithPanel เลือกแอปสำหรับ **ไฟล์ที่ไม่มีนามสกุล** แล้วกด **นำไปใช้** หลังจากนั้นไฟล์อย่าง `.env` และ `Dockerfile` จะเปิดในแอปนั้น

**ทำไม "เปลี่ยนทั้งหมด" ใน Finder ใช้กับไฟล์ `.env` ไม่ได้**
macOS ถือว่าไฟล์เหล่านี้เป็นข้อมูลทั่วไป (`public.data`) และไม่อนุญาตให้เปลี่ยนแอปเริ่มต้นของประเภทนี้ผ่าน API สาธารณะ OpenWithPanel หลีกเลี่ยงข้อจำกัดนี้ด้วยแอปผู้ช่วย

**จะตั้ง VS Code, Zed หรือ Sublime Text เป็นโปรแกรมแก้ไขเริ่มต้นสำหรับไฟล์โค้ดได้อย่างไร**
เลือกโปรแกรมแก้ไขสำหรับกลุ่ม **โค้ด** หรือสำหรับแต่ละรูปแบบ แล้วกด **นำไปใช้** นามสกุลที่ไม่มีประเภททางการใน macOS เช่น `.go` และ `.rs` ก็รองรับด้วย

**ย้อนกลับการเปลี่ยนแปลงทั้งหมดได้ไหม**
ได้ OpenWithPanel บันทึกการเชื่อมโยงดั้งเดิมไว้ตั้งแต่ครั้งแรกที่เปิดใช้ และจะไม่เขียนทับบันทึกนั้นเลย **กู้คืนเป็นค่าเริ่มต้น** จะชี้ทุกประเภทที่ถูกเปลี่ยนกลับไปยังแอปเดิม

**OpenWithPanel เก็บข้อมูลหรือทำงานเบื้องหลังหรือไม่**
ไม่ OpenWithPanel ไม่เก็บข้อมูล เชื่อมต่ออินเทอร์เน็ตเฉพาะเมื่อคุณเลือก **ตรวจหาอัปเดต…** ไม่ติดตั้งเอเจนต์เบื้องหลัง และไม่ทำงานต่อหลังจากคุณออกจากแอป **การตั้งค่า › สิ่งที่ OpenWithPanel เขียน** จะแสดงทุกตำแหน่งที่แอปเขียนข้อมูลลงไป

**ทำไม OpenWithPanel ไม่ใช้ sandbox**
macOS ไม่อนุญาตให้แอปที่อยู่ใน sandbox เปลี่ยนแอปเริ่มต้น OpenWithPanel จึงใช้ hardened runtime แทน

## ข้อจำกัดที่ทราบ

- บน macOS `.ts` ถูกรู้จักเป็นรูปแบบวิดีโอ (MPEG-2 transport stream) และการเปลี่ยนจะกระทบไฟล์วิดีโอจริง กลุ่มโค้ดจึงครอบคลุมเฉพาะ `.tsx` ของ TypeScript ในทำนองเดียวกัน สำหรับ macOS แล้ว `.r`, `.exs` และ `.fs` คือทรัพยากร Rez ไฟล์แซมเพลอร์ของ Logic และเชเดอร์ จึงไม่อยู่ในกลุ่มโค้ด
- การตั้งค่าประเภทไฟล์อาศัยกลไกของระบบที่ไม่มีเอกสาร ซึ่งอาจใช้งานไม่ได้หลังอัปเดตระบบ หากเกิดขึ้น ประเภทไฟล์ทั่วไปจะกลับไปใช้ API ของระบบโดยอัตโนมัติ (ยืนยันหนึ่งครั้งต่อประเภท) และไฟล์ที่ไม่มีนามสกุลใช้กฎโฟลเดอร์แทนได้
- macOS อนุญาตให้แอปอ่านได้เฉพาะบันทึกของโปรเซสตัวเอง รายงานการวินิจฉัยจึงไม่มีบันทึกของ OpenWithPanel Helper หากต้องการ ให้ค้นหา `net.zhaojian.openwithpanel` ในแอปจอคอนโซล
- คำแปลของอินเทอร์เฟซยังไม่ได้รับการตรวจทานโดยเจ้าของภาษา

## สร้างจากซอร์สโค้ด

ต้องใช้ Xcode 27

```sh
swift test --package-path OpenWithPanelKit
xcodebuild -project OpenWithPanel.xcodeproj -scheme OpenWithPanel build
```

หากต้องการสร้าง DMG:

```sh
scripts/package.sh
```

ผลลัพธ์จะอยู่ใน `.build/dist/` พร้อม Homebrew cask ที่สร้างจาก `packaging/openwithpanel.rb` โดยกรอกเวอร์ชันและ checksum ไว้แล้ว หากไม่ตั้งตัวแปรสภาพแวดล้อม แอปจะถูกเซ็นแบบ ad hoc และไม่ผ่านการ notarize ในกรณีนี้ DMG จะมี `First Launch.txt` ตั้ง `DEVELOPER_ID` (ชื่อใบรับรอง Developer ID Application) เพื่อเซ็นด้วยใบรับรองนั้น และตั้ง `NOTARY_PROFILE` (โปรไฟล์ข้อมูลประจำตัวที่บันทึกด้วย `xcrun notarytool store-credentials`) เพิ่มเติมเพื่อ notarize และ staple

รุ่นเผยแพร่สร้างโดยเวิร์กโฟลว์ GitHub Actions ใน `.github/workflows/release.yml` วิธีเซ็นและวิธีเผยแพร่รุ่นใหม่อธิบายไว้ใน [docs/release.md](../release.md)

## โครงสร้างโปรเจกต์

- `OpenWithPanelKit/`: แพ็กเกจ Swift ภายในเครื่อง `OpenWithPanelCore` มีตรรกะทั้งหมด ส่วน `OpenWithPanelPlatform` ห่อหุ้ม API ของระบบ
- `Apps/OpenWithPanel/`: แอปหลัก (SwiftUI)
- `Apps/Helper/`: แอปผู้ช่วยที่ฝังอยู่ในแพ็กเกจของแอปหลัก
- `scripts/`, `packaging/`: สคริปต์สำหรับแพ็กเกจและเทมเพลต Homebrew cask
